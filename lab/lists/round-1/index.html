What testing showed
  1. The list's name is a field: the same pill, fill and overline as the things inside it.
  2. Three chevrons with three meanings: pick a list, fold the list, add a list.
  3. The grip is darker than its row, so it reads as a gap, and row text starts further right than the header's.
  4. The check box's outline is the strongest mark in the row.
  5. "Add another task list" reads as a link, and its chevron as a dropdown.
  6. Session rows are raised and task rows recessed; session tools are loose icons, task tools a menu.

Sessions
What changed
  1. The list's name is a heading, not a field. Only rows are filled, so parent and child differ by type and by surface.
  2. One chevron: it leads the heading and folds the list. Switching the list moved into the list's menu.
  3. No grip gap: the chevron, check boxes and plus share one column, names share the next. The grip shows on hover, at the row's end.
  4. A smaller check box with a hairline outline, so the text leads.
  5. "Add task list" is a plain button that opens the picker.
  6. Sessions use the same row: one tone, one menu, the same grip.

Option B: tabs

One list in view at a time. Nothing folds, so nothing needs a chevron.

What changed
  1. Lists are tabs under the session's name: clearly the parent, with the tasks left to do as a count.
  2. No chevrons at all. A tab shows its list; the other lists wait behind their tabs.
  3. Rows are flat and start at the card's edge. The grip appears in the margin on hover.
  4. The quiet check box; a ticked one is a soft tint, since "done" isn't an action.
  5. A plus after the last tab adds a list, as in a browser.
  6. Sessions use the same flat row; tools appear on hover in one menu.
